# تمارين الترتيب (Flutter)
نفس بنية مشروع school_control_ready: مجلد android كامل، وملف build-apk.yml يعيد توليد ملفات المنصة ثم يحلل ويختبر ويبني APK.
- صفحة التطبيق: assets/index.html تُقدَّم عبر خادم محلي (localhost:8080) ليعمل الميكروفون.
- الصلاحيات: الإنترنت (للخادم المحلي) والميكروفون.
- الناتج: Artifacts باسم arrange-teacher-apk.
